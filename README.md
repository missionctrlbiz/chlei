##  About CHLEI

Community & Health Links Empowerment Initiative (CHLEI) is a leading humanitarian and development organization founded in 2006, working across North Central and North East Nigeria. With **ECOSOC status** and **UNFCCC Observer Status**, CHLEI has impacted over **300 communities** and **9,000,000 lives** through comprehensive interventions.

##  Our Mission

To empower vulnerable communities through integrated programs that promote health, education, sustainable livelihoods, and peacebuilding, while building resilient systems that can withstand and adapt to challenges.

##  Our Vision

A world where every community has access to quality healthcare, education, sustainable livelihoods, and lives in peace and harmony.

##  Our Programs

###  Health & Mental Wellness
Providing accessible healthcare services and mental health support to underserved communities through MHPSS programs and community health initiatives.

###  Education & Youth Development
Empowering the next generation through quality education, skills development, and youth leadership programs.

###  Climate Action & Environmental Sustainability
Leading environmental conservation initiatives, promoting climate resilience, and implementing sustainable agricultural practices.

###  Peacebuilding & Conflict Resolution
Fostering dialogue, reconciliation, and sustainable peace in conflict-affected communities through evidence-based interventions.

###  Livelihood & Economic Empowerment
Creating opportunities for sustainable income generation, women's economic empowerment, and financial inclusion.

###  Governance & Civic Engagement
Strengthening democratic institutions, promoting transparency, and fostering active citizenship and community participation.

##  Technical Stack

- **UI Library**: React 19

- **Styling**: Bootstrap 5 + Custom SCSS
- **Animations**: AOS, GSAP, Swiper
- **Icons**: Iconify
- **Interactive Components**: CountUp, Swiper slider

##  Getting Started

```bash
# Clone the repository
git clone https://github.com/missionctrlbiz/chlei.git
cd chlei

# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view the site.
